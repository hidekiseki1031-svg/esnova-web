Problem

日本発のスタートアップが
米国進出で直面する5つの壁

⚖️

法律・契約

Delaware C-Corpの設立方法がわからない。契約書の英語が読めない。弁護士の探し方も不明。

💰

財務・会計

米国銀行口座の開設に手間取る。経理ツールの設定・運用ができない。

📋

バックオフィス

請求書・支払い・書類管理で経営者の時間が奪われる。コアビジネスに集中できない。

🛂

就労ビザ

創業者・社員のビザ取得が複雑。E-2・L-1・H-1B等の選択判断が困難。

🚀

Go-To-Market

現地顧客開拓・マーケ戦略が立てられない。商習慣・営業ネットワークが不足。

これらすべてを、月額一定料金でまるごと解決するのが Backstage™ です。

Solution

8のサービスで、
進出に関わるCFO全業務をカバー

🏢

法人設立

米国法人（C-Corp）設立をEIN取得まで一括サポート。設立書類一式を全管理。

🏦

銀行口座開設・資金管理

非米国人・非居住者でも対応。米国銀行口座の開設および送金・支払等の資金管理を丸ごとサポート。

🖥️

オフィス・インフラ設定

バーチャルオフィス契約、SaaS・クラウドツールの導入設定、ITインフラ整備。米国でのビジネス環境を即日構築。

📊

経理・会計運用・決算

月次財務レポート、決算書作成、CF管理、会計ツールの設定・運用。日本在住スタッフが対応。

📈

税務申告

DE州・CA州等への税務申告。提携会計事務所との窓口を一括対応。

✈️

ビザ取得サポート

E-2・L-1・O-1等、提携弁護士と連携。書類作成・確認・提出サポートを一括対応。

🛡️

保険アレンジ

ビジネス保険の選定と代理店交渉。Workers Comp・General Liability等の手配。

OPTIONAL
🏖️

401(k)プラン設定

退職年金プランの選定・プロバイダーとの手続き。従業員採用時に必須。
